# Meningslöshetsmaskinen 🎨

Ett litet experiment om mänsklig kreativitet och AI-loopar: färg utan mål.

## Kör lokalt

Öppna `index.html` direkt i en modern webbläsare. Ingen installation, server eller byggkedja behövs.

## Funktioner

- Klicka eller dra på duken för att måla.
- **Kasta färg:** lägg till en slumpmässig färgfläck.
- **Låt slumpen måla:** en enkel, stoppbar loop med högst 28 fläckar per omgång.
- **Tolka verket:** lekfulla, påhittade kommentarer, inte riktig bildanalys.
- **Börja om:** rensa allt.
- **Spara PNG:** exportera bilden direkt på din dator.

Allt körs lokalt i webbläsaren. Inga externa beroenden eller nätverksanrop. Projektet är avsiktligt fristående från resten av repot.

> Allt som är vackert behöver inte vara användbart.
